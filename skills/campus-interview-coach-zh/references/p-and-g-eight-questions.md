# P&G Eight Questions

Use this file when the user asks about `宝洁八大问`, structured behavioral interviews, competency interviews, leadership-principle interviews, or HR questions that clearly map to fixed dimensions.

Do not treat the wording as the real task. Treat the competency as the real task.

## Default evaluation rule

For each question, judge the answer on five dimensions:
- `story fit`: does this story actually match the competency
- `ownership`: can we clearly see what the user personally did
- `difficulty`: was there a real challenge, conflict, risk, or tradeoff
- `result`: is there a concrete outcome
- `reflection`: is there a lesson, change, or self-awareness point

If two stories both fit, prefer the story with:
- clearer personal ownership
- more visible tradeoffs
- stronger business or team impact
- better follow-up resilience under pressure

## The eight questions and their competency mapping

### 1. 设定高目标并最终实现

Prompt:
- `请你举一个具体的例子，说明你是如何设定一个高目标，并最终实现了它。`

Core competency:
- drive
- resilience
- ambition with execution

What interviewers want:
- whether the user sets a challenging target voluntarily
- whether the target is specific and meaningful
- whether the user sustained action through setbacks

Best story types:
- self-driven project with a hard deadline
- stretched KPI or resource-constrained delivery
- difficult growth, campaign, research, or launch target

Common fail pattern:
- the goal was assigned by others and the user never re-owned it
- the target was vague
- no obstacle or persistence was visible

### 2. 团队中主动承担并发挥领导作用

Prompt:
- `请举例说明你在一项团队活动中如何采取主动性，并起到领导者的作用，最终获得你所希望的结果。`

Core competency:
- leadership
- influence
- initiative

What interviewers want:
- not title, but influence
- whether the user aligned others, handled friction, and moved the team

Best story types:
- cross-functional project push
- taking ownership when no clear owner existed
- resolving coordination gaps or conflicts

Common fail pattern:
- only describes teamwork, not leadership
- says `我们` too much and `我` too little
- no example of influencing others

### 3. 获取信息、制定关键点并做出决策

Prompt:
- `请你描述一种情况，在这种情况下你需要获取相关信息，制定关键点，并决定采取哪些步骤来获得期望的结果。`

Core competency:
- analysis
- judgment
- decision-making

What interviewers want:
- how the user handled ambiguity
- how they collected information and chose a path
- whether they can prioritize instead of drowning in data

Best story types:
- diagnosing a stalled project
- designing a marketing or research plan under uncertainty
- choosing among options with incomplete information

Common fail pattern:
- only describes data collection, not decision criteria
- gives process without showing why one route was chosen

### 4. 用事实履行对他人的承诺

Prompt:
- `请你举一个例子说明你是如何通过事实来履行你对他人的承诺的。`

Core competency:
- integrity
- reliability
- accountability

What interviewers want:
- whether the user is trustworthy
- whether they take promises and deadlines seriously
- whether they finish difficult commitments instead of hiding from them

Best story types:
- critical deadline ownership
- fixing a near-failure after committing publicly
- taking responsibility for a deliverable with reputational risk

Common fail pattern:
- answer becomes a generic `我很负责`
- no promise, no risk, no proof

### 5. 与他人有效合作实现重要目标

Prompt:
- `请你举一个例子，说明你有效地与人合作，共同实现了一个重要目标。`

Core competency:
- collaboration
- communication
- conflict management

What interviewers want:
- the user's role in the team
- how they coordinated differences and built trust
- whether they can move toward a shared goal

Best story types:
- multi-party project with dependencies
- team under deadline pressure
- stakeholder alignment across functions

Common fail pattern:
- only says the team worked well together
- no disagreement, no coordination method, no role clarity

### 6. 提出创新建议并推动活动成功

Prompt:
- `请你举一个例子，证明你提出了一个创新的建议/想法，对一个活动的成功起到了至关重要的作用。`

Core competency:
- innovation
- problem solving
- initiative with impact

What interviewers want:
- whether the idea was actually new in context
- whether the user pushed it through, not just suggested it
- whether it mattered to the result

Best story types:
- new workflow, new angle, new mechanism, new content or activation format
- process improvement that materially changed efficiency or effect

Common fail pattern:
- idea was minor or cosmetic
- innovation stayed at suggestion level
- no evidence it affected the outcome

### 7. 评估情况、抓重点并获得预期结果

Prompt:
- `请你举一个具体的例子，说明你是如何评估情况，并将精力集中在最重要的事情上，从而获得了预期的结果。`

Core competency:
- prioritization
- execution focus
- time and resource management

What interviewers want:
- whether the user can identify the leverage point
- whether they can resist doing everything at once
- whether prioritization improved results

Best story types:
- multi-thread project with limited time
- campaign or launch under deadline pressure
- choosing the key path in a messy operational problem

Common fail pattern:
- describes hard work, not prioritization
- says `我都兼顾到了`
- no explicit tradeoff

### 8. 学习新技术/新知识并应用到实际工作中

Prompt:
- `请你举一个例子，说明你如何学习了新技术/新知识，并将其应用于实际工作中。`

Core competency:
- learning agility
- adaptability
- conversion from learning to practice

What interviewers want:
- whether the user learns quickly and uses new knowledge effectively
- whether they can apply knowledge to a real problem
- whether they can keep up with changing tools or contexts

Best story types:
- learning a tool and using it to improve a workflow
- fast onboarding into a new business domain or method
- AI/tooling/data skill applied to real output

Common fail pattern:
- only talks about studying, not application
- tool name-heavy but impact-light

## Story reuse strategy

Default rule:
- do not reuse one story for more than 3 questions unless the user has very limited material

Preferred coverage:
- one project story
- one cross-team collaboration story
- one self-driven initiative story
- one research or analysis story
- one learning/new-tool story

If reusing the same story, explicitly shift the lens:
- leadership: emphasize influence and alignment
- decision: emphasize information gathering and criteria
- prioritization: emphasize what was *not* done
- innovation: emphasize the new mechanism and why it mattered

## Answer pattern

Use this oral pattern:
- one-sentence conclusion
- short context
- hardest part or key challenge
- 2 to 4 personal actions
- result with proof
- one-sentence reflection

Example answer skeleton:
- `如果要举一个最匹配这道题的例子，我会讲……`
- `当时最大的挑战是……`
- `我主要做了三件事……`
- `最后结果是……`
- `这件事让我学到……`

## Follow-up probes to pre-empt

Prepare these for almost every behavioral answer:
- `为什么是你来做，而不是别人？`
- `你当时有哪些备选方案？`
- `最难推进的阻力是什么？`
- `如果重来一次你会怎么做？`
- `这个结果里你个人贡献具体是什么？`

## Output suggestion

When the user asks to prepare `宝洁八大问`, prefer this output order:
1. `题目 -> 考点`
2. `最适合的故事`
3. `60-90 秒答题骨架`
4. `追问风险`
5. `如何把答案说得更像你本人`
